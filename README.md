# Ciclo Salta

Landing page del proyecto piloto de separación domiciliaria y compostaje local.

## Probar en local

Requisitos: Node.js 20.19+ o 22.12+.

```bash
git clone https://github.com/nicofinetti/compostaje.git
cd compostaje
git switch agent/redesign-landing-hero
npm install
npm run dev
```

Vite mostrará la dirección local, normalmente `http://localhost:5173`.

## Comandos

```bash
npm run dev      # servidor de desarrollo
npm run build    # compilación de producción
npm run preview  # vista previa del build
```
